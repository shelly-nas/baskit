KEY PRINCIPLES:
═══════════════

1. Dependency Rule: Dependencies point inward
   Frontend → Backend → Database

2. Layer Responsibilities:
   • Frontend: UI and user interaction
   • Backend: Business logic and rules
   • Database: Data persistence and retrieval

3. Data Flow:
   User Action → Service → Use Case → Repository → Data Source → Storage
   Storage → Data Source → Repository (maps to domain) → Use Case → Service → UI

4. Testing:
   Each layer can be tested independently by mocking its dependencies
